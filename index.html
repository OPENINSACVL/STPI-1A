Ajouter un cours ou une correction

Le site s'enrichit grâce aux étudiants. Trois étapes suffisent pour proposer une fiche.

Étape 1
Ouvrir le dépôt

Rendez-vous sur le dépôt GitHub OPENINSACVL/STPI-1A et créez un compte gratuit si besoin.

Étape 2
Écrire la fiche

Ajoutez votre contenu dans le dossier de la matière concernée, en suivant le modèle fourni.

Étape 3
Proposer la modification

Envoyez une pull request. Elle est relue, puis publiée sur le site.

À propos

STPI 1A Open est un projet étudiant indépendant. Il n'est ni édité, ni validé, ni soutenu par l'INSA Centre Val de Loire. Les contenus peuvent contenir des erreurs : vérifiez toujours avec vos cours et vos enseignants.
